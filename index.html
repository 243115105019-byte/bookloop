The textbook you need is on a senior's shelf.

BookLoop is a proposed campus platform where students buy, sell, rent, exchange or donate used academic books, filtered by department, semester, course code and edition.

Reuse Books. Reduce Costs. Share Knowledge.

Why this is needed

No single campus place helps students find the right textbook at a fair price.

New books cost a lot

Many are used for one semester, then sit unused.

The right edition is hard to find

Syllabus regulation and edition matter, and are rarely listed.

Listings are scattered

Students rely on WhatsApp groups, friends and seniors.

Usable books go to waste

Sellers and donors struggle to find interested students.

How it works

Two paths that meet at an on-campus book exchange.

If you have a book

  1. Register or log in
  2. Add details and photos
  3. Set a price, or choose rent, exchange or donate
  4. Publish the listing
  5. Reply to interested students
  6. Hand over safely on campus
  7. Mark the listing completed

If you need a book

  1. Register or log in
  2. Search by subject, semester, code or regulation
  3. Compare edition, condition and price
  4. Contact the owner
  5. Agree on the exchange details
  6. Collect the book and leave feedback

Both paths end at the same place: a safe handover inside your campus.

Proposed features

Academic filters

Department, semester, subject, course code, regulation, edition and condition.

Five ways to share

Buy, sell, rent, exchange or donate, all in one place.

Listing status

Mark books as available, reserved or completed.

Safety basics

Listing moderation, user reports and campus handover guidance, managed from an admin panel.

Why BookLoop is a good EDI project

These are the expected benefits. They still need to be tested in a pilot, and we have not yet checked competitors or prior work.

Social impact

  • Lower textbook costs for students
  • More sharing among students
  • Better access to academic resources

Environmental impact

  • Longer useful life for textbooks
  • Reuse instead of disposal
  • A circular approach to learning resources

Technical feasibility

  • Standard web tools and a database
  • Starts as a small campus prototype

Innovation and entrepreneurship

  • Academic details plus campus-based discovery
  • Five reuse options in one place
  • Can grow to other departments after validation

Resources needed

What it takes to build and test the project. Nothing here is claimed as already done.

Hardware

  • Laptop or desktop
  • Smartphone for mobile testing
  • Sample textbooks for the catalogue

Software

  • HTML, CSS, JavaScript and a frontend framework
  • Backend service or API
  • Database for users, listings and transactions
  • Git and GitHub
  • A design tool for wireframes

People

  • Frontend developer
  • Backend and database developer
  • UI/UX designer
  • Student testers and a faculty mentor

Campus operations

  • A pilot group on campus
  • Listing guidelines and moderation
  • Rules for condition, pricing, cancellations and safe handover
