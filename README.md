# BookLoop - Campus Textbook Reuse Platform

EDI project concept (U24ED411). A static website prototype.

## Run
Open `index.html` in any browser. No install or server needed.

## Files
- `index.html` - page structure and content
- `css/style.css` - styles (light and dark themes)
- `js/app.js` - catalogue search and filters, add listing, contact, admin mockup
- `assets/logo.svg`, `assets/favicon.svg` - logo and tab icon

## Notes
- Listings are sample data and reset on reload. A real version needs a backend database, login and moderation.
- Fonts (Bricolage Grotesque, Figtree) load from Google Fonts when online; system fonts are used offline.
- To add team details, edit the "Our team" section in `index.html`.
- Pilot metrics are placeholders until a real pilot study is run.
